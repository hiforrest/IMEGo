# IME直达：无论当前正在使用什么输入法，按下快捷键，直接开始豆包输入法语音输入

如果你当前正在使用其他输入法，想开始语音输入，需要先切到豆包输入法，再开启语音。

所以做了这个小工具：按下快捷键，切到豆包输入法并开始语音录入。

## 应用简介

1. **快捷键启动豆包语音**

   无论当前正在使用什么输入法，按下设定的快捷键，就会切到豆包输入法并开始语音录入。

   比如我自己设置的是 `Alt + Space`。打字过程中突然有一段内容不想敲，可以直接按快捷键开始说。

2. **也支持一键切换其他输入法**

   除了豆包语音，也可以分别给不同输入法绑定快捷键。

   比如一个快捷键切到微信输入法，另一个快捷键切到系统输入法，不需要在多个输入法之间循环切换。

## 适用人群

- 经常使用豆包语音输入的人
- 同时安装了多个输入法，希望通过快捷键直接切换的人

## 已知限制

- 需要提前安装豆包输入法
- 工具使用 AHK 开发，可能被误报病毒
